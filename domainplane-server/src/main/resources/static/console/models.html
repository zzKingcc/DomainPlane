添加模型

本地 Ollama：地址填 http://localhost:11434/v1（必带 /v1）； API Key 随便填个非空占位（如 ollama）；模型名取 ollama list 里的名字（带 tag，如 qwen2.5:7b）。
点右侧按钮拉取候选（仅候选池）。
只读提供商的 /models，不发任何试探请求
类型只能来自提供商元数据或你在这里的声明；读不到就留空，不会替你猜 —— 猜成对话模型会让向量 / 生图模型被误用（能绑到域、却当不了向量模型）。
向量维度必须与 ES 索引 mapping 一致；改维度后必须重建知识库索引， 否则新旧向量长度不符，写入会被 ES 拒绝。
