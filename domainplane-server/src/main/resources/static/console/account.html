修改密码

成功后所有旧登录态立即失效
不超过 72 字节（UTF-8 下中文约 24 个字符）。BCrypt 的硬上限，超出会被拒。
为什么改完会被踢下线？
凭证是签名式（HMAC）：实际签名密钥由【主密钥 + 密码哈希】派生，所以改密码不需要"通知"任何人， 全部旧凭证的签名会立刻对不上。
因此本次登录也会被踢掉。这不是缺陷，而是"改密码即踢人"的直接体现；保存后请重新登录。
