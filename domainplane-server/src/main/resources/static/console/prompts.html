可见工具与提示词的关系
可见工具 = 该域真实能用的工具集（声明留空或挂在根域的工具对全树可见； 挂在父域的工具，其所有后代域都能用）。 提示词不决定工具可见性：就算某个域一个字都没配，它对工具的限制照样生效，缺提示词只是体验降级。
