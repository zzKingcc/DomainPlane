# 管控台

所有配置都在浏览器里做，改完即生效。本文分两块：**页面能做什么**（使用者视角）、**前端怎么改**（维护者视角，含两套树的坑）。

---

## 1. 十一个页面

## 2. 页面与端点对照

下面按页面分组，只列"这页会用到的"端点；完整清单以源码里的 mapping 为准。

### 登录 / 账号 / 初始化

| 端点 | 用途 |
| --- | --- |
| `POST /admin/login` | 换凭证，下发 `Set-Cookie: domainplane_admin` |
| `POST /admin/logout` | 清 Cookie |
| `GET /admin/session` | 当前会话状态（免鉴权，用于判断是否已登录） |
| `POST /admin/password` | 改密码（默认口令下唯一放行的写操作） |
| `POST /admin/init` | 首次初始化（默认只允许本机） |

### 域空间

| 端点 | 用途 |
| --- | --- |
| `GET /admin/domains` | 域树全貌（纯内存，快） |
| `POST /admin/domains` | 建域 |
| `PUT /admin/domains/{id}/callable` | 可调用开关 |
| `PUT /admin/domains/{id}/tool-call-echo` | 工具过程是否回写模型 |
| `PUT /admin/domains/{id}/plan-display` | 是否把 PLAN 事件发给前端 |
| `PUT /admin/domains/{id}/body` | 绑知识体 |
| `GET /admin/domains/{id}/delete-impact` | 删域预演 |
| `GET /admin/domains/storage` | 软删宽限期（`deleteGraceMs`，树上的"剩余多久清除"） |
| `DELETE /admin/domains/{id}` / `POST /{id}/restore` | 软删 / 撤销（带 `?force=true` 立即清） |
| `GET /admin/domains/history` · `/history/{v}` · `POST /rollback` | 版本历史 / diff / 回滚（后端有，管控台页面未接） |
| `GET /admin/kb/stats` | 知识库数字（异步补数，60s 缓存） |

域空间页的关键约束：**先渲染树、再异步补数**。树与开关走 `/admin/domains`（纯内存），知识库数字走 `/admin/kb/stats`（可能要连远程）。放进同一个 `Promise.all` 等于没拆，慢的那个会拖住整页。

### 模型设置

| 端点 | 用途 |
| --- | --- |
| `GET/POST/DELETE /admin/provider-connections` | 连接增删查 |
| `POST /admin/provider-connections/resolve` | 取明文密钥（仅此一处） |
| `GET /admin/provider-presets` | 内置预设 |
| `GET/POST/DELETE /admin/model-profiles` | 档案增删查 |
| `PUT /admin/model-profiles/tuning` · `/return-thinking` · `/context-window` · `/custom-params` · `/protocol` | 卡片内就地改 |
| `POST /admin/model-profiles/test` · `/detect` · `/detect-all` | 连通性 / 探测 |
| `PUT /admin/model-bindings/{domain}` | 域绑定 |
| `PUT /admin/embedding-model` · `POST /embedding-model/rebuild` · `/purge` | 向量模型切换三入口 |
| `POST /admin/model-adapters/match` · `GET /admin/model-adapters` | 适配档案匹配 |
| `POST /admin/models?type=chat` | 拉上游模型候选 |

### 知识库

文档、健康、重建、换落点、绑定、删除都以知识体为起点（`/admin/bodies`）。v1 的 `/admin/kb/documents|rebuild|reindex` 已移除，只剩 `/admin/kb/stats` 给域页补数。

| 端点 | 用途 |
| --- | --- |
| `GET /admin/bodies` | 整页快照：体 + 槽位 + 绑定域 + 计数 + 无主索引 + `rawOptions` |
| `GET /admin/bodies/target?body=` | 上传前落点预检（纯读配置，不碰存储） |
| `POST /admin/bodies` · `PUT /{id}` | 建体 / 改名字与说明（唯一名与索引创建后冻结） |
| `PUT /admin/bodies/{id}/routes` | 换某一路落点：`?dryRun=true` 预演，正式调用先写满再切指针 |
| `GET /admin/bodies/{id}/health` | 三方维度对照（关键字 mapping / 向量集合 / 当前模型） |
| `POST /admin/bodies/{id}/rebuild` | 重建该体索引（`from=archive` 从原文，`reset` 清空） |
| `POST /admin/bodies/{id}/bind` · `/unbind` | 绑定 / 解绑域 |
| `GET/POST /admin/bodies/{id}/documents` · `DELETE /{docId}` | 文档表 / 上传（multipart）/ 删除 |
| `GET /admin/bodies/{id}/documents/{docId}/chunks` | 切片预览（优先读原文档案） |
| `GET /admin/bodies/{id}/documents/{docId}/raw` | 下载原始文件（未归档时 4xx 如实说明） |
| `DELETE /admin/bodies/{id}` | 删体（`confirm` 输名 + `keepRaw` 默认 true + `force` 一并解绑） |
| `GET /admin/kb/stats` | 域页的数字补数（只读聚合，60s 缓存） |

运维区（知识库页底部，默认收起）：

| 端点 | 用途 |
| --- | --- |
| `GET /admin/bodies/ops/diagnostics` | 逐连接列集合：归属 / 状态（在用·遗留·无主）/ 维度 / 切片 |
| `POST /admin/bodies/ops/adopt` | 把无主集合认领为知识体（索引名原样冻结） |
| `DELETE /admin/bodies/ops/collections` | 删遗留集合（输名确认；活体当前落点上的拒删） |
| `POST /admin/bodies/ops/merge` | 合并知识体（源体原文重灌进目标，源体不删） |

### 存储配置

| 端点 | 用途 |
| --- | --- |
| `GET/POST /admin/infra` | 读 / 整份保存（保存即热切换） |
| `POST /admin/infra/test` | 连接测试 |

页面按段给保存按钮，但提交的是**同一份** `redis + connections`（`POST /admin/infra` 整份覆盖），知识体不在这份请求里——它们走 `/admin/bodies`，避免只读回显反推着把 slug / 冻结索引冲掉。口令留空表示"不修改"。热切换时旧连接延迟 30s 销毁，在途请求不受影响。

### MCP / 实例 / 会话 / 提示词

| 端点 | 用途 |
| --- | --- |
| `GET/POST/DELETE /admin/mcp-connections` · `/{name}/toggle` · `/{name}/test` · `/{name}/tools` · `POST /{name}/tools/call` · `GET /{name}/events` | MCP 连接 / 工具目录 / 试跑（写操作需显式确认，每连接 60 秒 10 次）/ 事件记录（内存，重启清空）。`list()` 回 `protocolVersion` / `protocolEra`（`MODERN` 无状态 / `LEGACY` 会话）/ `capabilities` / `tokenInfo`，状态条与概览直接显示协商结果 |
| `GET/PUT /admin/mcp-bindings` | MCP 域绑定 |
| `POST /{name}/oauth/start` · `GET /{name}/oauth/callback` · `DELETE /{name}/oauth/token` | OAuth（撤销只是删本地凭据并重连，不回话授权服务器） |
| `GET /admin/instances` · `POST /{id}/mute` · `/restore` | 在线实例（`/offline` 后端有，页面没给按钮：吊注销只能由接口恢复） |
| `GET /admin/sessions/storage?domain=&limit=` · `/turns` · `/assembly` · `/export` · `POST /admin/sessions/clear` | 会话列表（一次 SCAN 同时返回全部域清单 + 按域精确筛选后的 top N；不含子域）/ 按轮号分页查档 / 装配清单 / 导出 / 单会话清空 |
| `GET/POST /admin/prompts` | 提示词读写 |
| `GET /admin/metrics` · `/metrics/history` | 指标快照 / 趋势 |
| `GET /admin/tools` | 已注册工具（含来源；后端有，11 个页面都没接） |
| `GET /admin/settings` · `POST /admin/settings` · `DELETE /admin/settings/{kind}` · `POST /admin/settings/test` | 模型兜底设置（兼容入口） |

## 3. 鉴权在页面上的表现

| 载体 | 范围 | 拦截方式 |
| --- | --- | --- |
| Cookie `domainplane_admin` | `/admin/**` | HttpOnly + SameSite=Lax |
| Header `X-DomainPlane-Credential` | `/api/agent/**` | 给 SDK 与脚本用 |

同源页面天然带 Cookie，所以管控台不需要在 JS 里存凭证。SDK 走 Header，两者共用同一套 HMAC 凭证。

未初始化时只放行 `/api/agent/health`——避免"服务起来了但什么都调不动，又看不出为什么"。详见 [11-鉴权与错误码](11-鉴权与错误码.md)。

## 4. 改前端：两套树，一个产物

这是本仓库最容易出错的地方，值得单独说清。

```
domainplane-server/
├── frontend/                            ← 源码树（esbuild 构建用）
│   ├── src/console.js                   导航/登录态
│   ├── src/core/{request,feedback}.js   api 层与提示
│   ├── src/pages/*.js                   11 个页面脚本
│   └── build.mjs                        构建脚本
└── src/main/resources/static/console/
    ├── *.html                           11 个页面骨架（直接手写）
    └── assets/page-*.js                 ★ 实际被服务的产物（入 git）
```

| 事实 | 后果 |
| --- | --- |
| 产物入 git、源码**没接进 maven** | 改源码不构建 = 页面没变，jar 照常打包成功 |
| 产物历史上被直接手改过 | 源码与产物已经双向漂移，整包重建会回退"只在产物里有的改动" |
| 产物里的中文编码**不统一** | 整包 `build.mjs` 没配 `charset`，重建出来会写明文中文；单页 `build-one.mjs` 配了 `charset: 'ascii'`（与历史产物一致）。历史产物里大量是 `\uXXXX`。实测 `page-domains.js` 两种混在一起。手改时别假设"全是转义"或"全是明文"，也别手动转义——以行为准，编码不承载语义 |

### 改一页的正确姿势

1. 先逐页对比 `frontend/src/pages/x.js` 与 `assets/page-x.js`，确认差异是有意的还是漂移。
2. 只重建这一页，**不要跑整包 `build.mjs`**：

```bash
cd domainplane-server/frontend
node build-one.mjs domains       # 可一次给多个页面名；iife / es2015 / charset ascii
```

3. 本机跑在 IDE 里（classpath = `target/classes`）时，把 html / css / js 三件拷到 `target/classes/static/console`；静态资源改完立即生效，Java 类要重启。

### 页面脚本的写法约束

用 **promise 链，不要 `async/await`**。`async` 会被 esbuild 降级成 `__async` 生成器包装，源码与产物就再也无法逐字对照，上面"先对比再重建"的流程直接失效。promise 链的产物基本等于源码再包一层 IIFE，两棵树可以保持同文。

## 5. 指标与可观测

| 项 | 值 |
| --- | --- |
| 采样间隔 | 10s（`MetricsSampler`） |
| 存放 | 进程内环形缓冲 |
| 对外 | `GET /admin/metrics`（快照）、`/admin/metrics/history`（趋势） |

指标是进程内的，重启即清零，也不跨实例聚合。它解决的是"刚才那几分钟发生了什么"，不是"这个月的容量趋势"——后者需要外接监控，目前没做（Micrometer / OTel 未接）。

## 6. 踩过的坑

**页面文案要干爽。** 解释性文字（页头副标题、底部提示卡、折叠说明、落盘路径提示）不上页面，只留操作性文字；高危操作的警示放确认弹窗，不放常驻红字。这条是明确的产品口径，不是风格偏好。

**`/admin/domains` 变快是有前提的。** 它只读内存，不含任何远程调用；一旦有人往这里加"顺便查一下知识库数量"，整页会退回到几秒级。

**`GET /admin/session` 免鉴权是有意的。** 它只回"是否已登录 + 账号名"，用于登录态判断；别往里加配置内容。

**改 HTML 不用构建。** 只有 `page-*.js` 是产物；`*.html` 是手写的，改完直接生效。但同样要拷到 `target/classes`。

**删域、重灌、换落点、合并知识体都没有"后台任务"概念。** 接口同步跑完才返回，慢就是慢；前端必须自己给等待态，不要指望轮询一个有进度字段的接口。逐文档进度与暂停还没做。
