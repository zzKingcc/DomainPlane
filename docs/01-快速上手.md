# 快速上手

目标只有一个：**把服务跑起来，配到能对话**。为什么这么设计、内部怎么运转，不在本篇。

---

## 1. 前置条件

| 依赖 | 要求 | 不满足会怎样 |
| --- | --- | --- |
| JDK | 21+ | 编译不过（`maven.compiler.release=21`） |
| Maven | 3.6.3+ | 构建不了 |
| Redis | 任意可用版本 | 服务能启动；对话报 `90005 DEPENDENCY_NOT_CONFIGURED` |
| Elasticsearch | 9.x（需 `dense_vector index:true`）或 Qdrant | 服务能启动；知识库相关操作报 `60007` / `60008` |
| 对话模型 | 不内置 | 必须在管控台自建服务商连接与模型档案 |

关于"启动依赖"需要说清楚一件事：**启动期不建立任何强网络依赖**。ES / Qdrant 的连接在第一次真正检索时才建；MCP 连接是后台线程拉起的；连 Redis 都是 Lettuce 懒连接——未配置时单实例守卫直接跳过，服务照常起。所以"起不来"和"没配好"是两件事，排障时别混。

---

## 2. 构建与启动

```bash
# 构建（产物：domainplane-server/target/domainplane-v1.0-beta.2.jar）
mvn clean package

# 启动（本机开发务必覆盖配置目录，否则会写到本盘根目录下的 /var/lib/...）
java -DDOMAINPLANE_SETTINGS_PATH="$PWD/.dev/config" \
     -jar domainplane-server/target/domainplane-v1.0-beta.2.jar

# 验证
curl http://localhost:9527/health
# {"code":0,"status":"UP","service":"domainplane-server","version":"v1.0-beta.2"}
```

**`-D` 必须写在 `-jar` 之前**。写在后面会被当成传给应用的普通参数，静默不生效——表现是"配置明明改了却没生效"，或配置写到了系统盘根路径。

Maven 直跑也可以，但要先把内部模块装进本地仓库（或带 `-am`）：

```bash
mvn -pl domainplane-server -am spring-boot:run
```

### 启动参数

| 参数（环境变量同名） | 默认 | 作用 |
| --- | --- | --- |
| `DOMAINPLANE_SERVER_PORT` | `9527` | HTTP 端口 |
| `DOMAINPLANE_SETTINGS_PATH` | `/var/lib/domainplane/config` | 落盘配置目录 |
| `DOMAINPLANE_STORAGE_PATH` | `/var/lib/domainplane/blobs` | Blob 根目录（切片原文 + 媒体附件） |
| `DOMAINPLANE_EXPORT_PATH` | `/var/lib/domainplane/chunks` | 切片预览 txt 导出目录 |
| `DOMAINPLANE_LOG_PATH` | `/var/log/domainplane` | 日志目录 |
| `DOMAINPLANE_LOG_LEVEL` | `INFO` | 业务包日志级别 |

平台默认路径（不配任何东西时的落点）：

| 用途 | Linux | Windows | macOS |
| --- | --- | --- | --- |
| 配置 | `/var/lib/domainplane/config` | `%ProgramData%\DomainPlane\config` | `/Library/Application Support/DomainPlane/config` |
| 日志 | `/var/log/domainplane` | `%ProgramData%\DomainPlane\logs` | `/Library/Logs/DomainPlane` |
| 切片预览 | `/var/lib/domainplane/chunks` | `%ProgramData%\DomainPlane\chunks` | `…/DomainPlane/chunks` |

## 3. Docker 运行

```bash
# 1. 先 mvn clean package，把 jar 和 Dockerfile 放同一目录
docker build -t domainplane-server:v1.0-beta.2 .

# 2. config 卷必须挂：账号、模型、存储连接都在里面
docker run -d --name domainplane -p 9527:9527 \
  -v domainplane-config:/var/lib/domainplane/config \
  -v domainplane-chunks:/var/lib/domainplane/chunks \
  -v domainplane-blobs:/var/lib/domainplane/blobs \
  domainplane-server:v1.0-beta.2
```

镜像内建 `HEALTHCHECK`，打的是免鉴权的 `GET /health`。不挂 `config` 卷，重建容器等于账号回落种子、所有配置重填。

## 4. 首次配置：四步

浏览器打开 <http://localhost:9527/console/login.html>，用种子账号 `domainplane` / `domainplane` 登录。

### 第一步：存储配置（`存储配置` 页）

- **Redis 必填**，否则对话第一轮就报 `90005`。
- **Elasticsearch / Qdrant 按需**：只有要用知识库才需要。可以配多条连接（命名实例），知识体再从连接里挑。
- 保存即热切换：不需要重启，旧连接延迟 30s 销毁，在途请求不受影响。
- 保存时会顺带做两件事：能力校验（关键字只能 ES，向量 ES 或 Qdrant）+ Redis 持久化策略自检。**只告警、不拒绝保存**，告警以 toast 弹出。

### 第二步：模型（`模型设置` 页）

顺序不能乱：

1. **服务商连接**：填 `name / baseUrl / apiKey`。内置常见服务商预设，选一个自动填地址。
2. **模型档案**：选连接 + 填模型名（`modelName`），声明端点族（chat / embedding / rerank / images / tts / asr / video）。
3. **跑一次能力探测**：探测会真打上游（chat/completions 带图/带音频、images/generations、audio/speech、audio/transcriptions、embeddings、rerank），把确认到的能力并集写回档案。标准 OpenAI 规范的服务商常常读不出模态，**不探测就等于没声明能力**。
4. **绑定到域**：`PUT /admin/model-bindings/{domain}`。向量模型是全局唯一，单独一栏。

### 第三步：域（`域空间` 页）

根域 `default` 已预置。规则只有一条：**可调用单元必须是叶子域**。给子域打上"可调用"后，父域就不再是可调用单元，请求会报 `10010`。

### 第四步：改默认口令（`账号` 页）

默认口令下，管控台的**变更类写操作**会被拒绝并返回 `10008`（`/admin/password` 除外，否则改不了密码）。只读操作不受影响。

## 5. 验证一遍完整链路

```bash
# 1) 登录换凭证（响应体含 credential，同时下发 Set-Cookie: domainplane_admin）
CRED=$(curl -s -X POST http://localhost:9527/api/agent/login \
  -H "Content-Type: application/json" \
  -d '{"username":"domainplane","password":"domainplane"}' \
  | sed -n 's/.*"credential":"\([^"]*\)".*/\1/p')

# 2) 发起一轮对话（SSE：TOKEN … → DONE）
curl -N -X POST http://localhost:9527/api/agent/chat \
  -H "Content-Type: application/json" \
  -H "X-DomainPlane-Credential: $CRED" \
  -d '{"sessionId":"demo-1","domain":"default","message":"你好"}'

# 3) 停止（幂等，不可恢复）
curl -X POST "http://localhost:9527/api/agent/stop/demo-1?domain=default" \
  -H "X-DomainPlane-Credential: $CRED"
```

被 `INTERRUPT` 事件挂起（有工具需要审批）时：

```bash
curl -N -X POST "http://localhost:9527/api/agent/resume?sessionId=demo-1&approved=true&domain=default" \
  -H "X-DomainPlane-Credential: $CRED"
```

`domain` 必须与 `chat` 时一致——会话键是 `(域, sessionId)`，换域就是另一段会话。

## 6. 起不来 / 配不通对照表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `90005 DEPENDENCY_NOT_CONFIGURED` | Redis 没配 | 存储配置页填 Redis，保存即生效 |
| `10010 DOMAIN_NOT_CALLABLE` | 用的是父域或未标记可调用的域 | 域空间页勾选该叶子域，或换用叶子域 |
| `91001 MODEL_NO_VISION` | 这轮带了图片，域没绑视觉模型 | 换文本提问，或给域（含祖先域）绑一个 `input` 含 image 的档案并先探测 |
| `10008` | 还在用默认口令 | 账号页改密码 |
| `60007` | 召回策略与后端能力不匹配（如 `strategy=vector` 但只配了关键字槽） | 补齐对应槽位的连接，或调整策略 |
| `70004 CHECKPOINT_ERROR` | 检查点读写失败（多因 Redis 抖动或超时太短） | 调 `domainplane.redis.timeout`（默认 5s） |
| `20002 SYSTEM_BUSY` | 并发闸门或线程池饱和 | 稍后重试；容量见 `domainplane.agent.concurrency-limit` |
| `30003 SESSION_BUSY` | 同一会话上一轮还没结束 | 等结束或先 `stop` |
| 配置改了不生效 | `-D` 写在了 `-jar` 后面 | 参数前移，或改用环境变量 |
| 忘了管理员密码 | — | 删掉 `config/accounts.json` 重启，回落种子账号 |

`frontend/src` 改了页面却没变化：管控台前端是 esbuild 构建产物**入 git**，必须重新构建（见 [10-管控台](10-管控台.md) 的"改前端"一节）。
