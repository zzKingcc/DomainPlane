## 1 配置与启动

- **`domainplane.ai.prompt.*` 缩进错位会静默失效** —— yaml 中 `prompt:` 若挂在已注释的 `ai:` 之下，实际键变成 `domainplane.server.prompt.*`，`@ConfigurationProperties` 不认，系统提示词静默为 null、不注入 `SystemMessage`。→ 改完 yaml 必须做键路径体检；启动摘要里确认提示词已加载。
- **`domainplane.rag.logging.*` 同类失效** —— 缩进错位后回落默认值恰好与预期相同，表面"正常"，实际 `DOMAINPLANE_LOG_PATH` 改不动日志目录。→ 校验键路径，不要靠"看起来对"。
- **同一层级出现重复键会直接起不来** —— Boot 3.x 的 SnakeYAML 抛 `DuplicateKeyException`，不再"后者覆盖前者"；缩进错位则相反，不报错只静默失效。两种失败模式都需要专门的键路径检查脚本。
- **"还没配"是合法初始态，不是错误** —— 启动期因未配置而失败会形成死锁：起不来 → 管控台打不开 → 配置填不上。→ 启动期只以横幅 INFO 陈述，失败推迟到调用点（`90005` + WARN）。
- **首次启动死锁的另一种形态** —— 把 ES 连接写进 yaml 且要求启动期必达时，配置一旦挪到管控台就永远进不去管控台。→ 启动期干脆不碰 ES（知识库索引本就按需创建），未配置只打 INFO，失败推迟到调用点。
- **"填错"不能只在保存时判格式** —— 协议白名单、端口范围、库号非负、地址里混 URL 或端口这类形态错误要在保存期拦下，"测试连接"与保存两处都调同一套校验。

## 2 模型与向量维度

- **上游对 `dimensions` 是静默忽略的** —— 实测传 `512` / `9999` / `-1` / `1.5` 均返回 HTTP 200 且返回 1536 维、不报错。→ 只能比对返回向量的实际长度，看状态码必误判。
- **绝不能读 `model.dimension()` 做校验** —— 一旦设置了 `dimensions`，该方法优先返回配置值而不再探测，等于"填什么返回什么"，校验形同虚设。→ 读返回向量的长度。
- **向量维度三处必须同源** —— 测试连接、`EmbeddingModel` 构建、ES 索引 mapping。任一处不同就会出现"索引维度与写入向量长度不符"，且不会自愈（mapping 的 `dims` 建好改不了）。→ 唯一取值口径 `LlmModelHolder#effectiveEmbeddingDimension()`。
- **索引已存在时不会自动改维度** —— `createIndexWithIkMapping` 见索引存在直接返回，日志只说"已存在跳过"。→ 改维度必须删索引重建。
- **改完维度必须重建索引，重建会清空内容** —— 重建是"删旧 + 按新维度建"，之后文档需重新上传。→ 保存前二次确认，并留存文档原件。
- **保存期预检的四个结论各有后果** —— `OK` 直存；`NEEDS_REBUILD` 拒存并要求二次确认；`DECLARED_MISMATCH` 拒存；`UNKNOWN` 必须放行。→ 若"无法实测"也拒存，用户连改 Key 自救都做不到。
- **保存成功但重建失败不是成功** —— 页面应显示警告而非错误，并提示上传与检索在重建前不可用。
- **补全 Key 的回落链有缺口** —— 首次只填文本模型、向量模型留空时，测试向量连接可能报"请先填写向量模型"，而用户自认已填。→ 回落链要覆盖当前表单的候选值，不能只取已保存设置。
- **模型名列表与授权范围无关** —— 目录里多数模型实际返回 403，而能用的模型未必在目录里。→ 列表只是候选池，"选中"不等于"可用"，以试调为准。
- **维度下拉的 64~2048 是常见值，不是该模型的支持范围**。
- **`401` 与 `403` 必须分开** —— 401 是钥匙错、403 是钥匙对但没开这扇门。合并后会引导用户反复重填 Key，永远改不对。
- **向量侧选错模态与真参数错误同码** —— 都返回 400 `invalid_parameter_error`，无法据此区分，只能笼统报"连接失败"。

## 3 存储（Elasticsearch / Redis）

> **本节及以下章节内容丢失，需重新补写。**

- **IK 分词器缺失不报错** —— 缺 IK 时回退 ES 默认分词器，索引照建、灌库照成功，只有中文检索质量下降且无任何提示。→ 保存/测试时主动探测 `ik_max_word`。
- **"探测不到"不等于"没有"** —— 只读账号探测 IK 会得到假告警。→ 探测结果分三态（可用 / 确认未安装 / 未探测），不要二值化。
- **不要按版本号硬拦** —— 版本号不等于能力；读不到版本（只读账号无集群监控权限）就拒绝，等于逼客户开高权限账号。→ 给出档位判断与提示，一律不阻断保存。
