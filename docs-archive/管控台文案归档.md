# 管控台文案归档（2026-11-01 精简）

本次把管控台各页的 AI 生成长说明从页面上移除，原则：

- 页面只留**操作性文字**（字段名、placeholder、按钮、状态行、确认弹窗）。
- 解释性、设计 rationale、后果说明类文字全部移入本文档。
- 高危操作（重建索引、跨后端重灌、删除连接/文档、换 Redis 数据源）的警示保留在**点击时的确认弹窗**里，不做常驻文字。

## 存储配置（infra.html）

- 页头：「三处存储 —— 关键字、向量、原文；**连接**存地址，**知识体**一个体只干一件事。」
- 01 运行状态存储副标题：「会话记忆、审批断点、会话归档都落在这里」（卡片右上角短注「会话记忆 / 断点 / 归档」保留）
- Redis 兼容说明块（含折叠）：「为什么只看拓扑，不判版本」—— 只用 GET/SET/PING/INFO/DBSIZE，2.6 以上都有；断点是拓扑（集群/多数云托管只有 0 号库）；数据靠 `domainplane:` key 前缀隔离。
- 库号 help：「默认 0。⚠️ 换地址或换库号等于换数据源：历史会话与未完成的断点留在旧库，不会迁移。」（现仅留「默认 0」；换数据源确认弹窗已覆盖此提示）
- 保存按钮旁 hint：「**只保存本段**；连接池与命令超时仍取服务端 yaml。」
- 02 连接副标题：「按用途分成三段；一套地址只有一份，可被多个知识体复用」
- 03 知识体副标题：「一个知识体 = 一套知识库，最多两路召回（关键字 / 向量，各可选）；域到「域空间」里各绑一个」
- 页底说明卡（整块删除）：
  - 「清空表单」只清本页输入框，**不发请求、不动线上配置**。口令框清空后语义是"不修改"，不会抹掉服务端已存的密码。
  - 知识体里关键字与向量各占一路：两路都选 = 混合召回，只选一路 = 单路召回。原文一律写内置磁盘，不需要连接，也不参与检索。
  - 设置文件：`D:\var\lib\domainplane\config\infra-settings.json`（知识库索引 `domainplane_kb_*`，由接口动态回填）
- 连接弹窗预设 hint：「先选一个预设，再在下面填这台实例的地址与认证。」
- 连接名称 help 原文：「同一类型下不能重名；名称会出现在知识体的连接下拉里。」（现仅留「同类型内不能重名。」）
- ES 兼容折叠说明：「为什么不按版本号拦截？缺 IK 分词器会怎样？」—— 平台只依赖 info/ping/count/search/indices.*/bulk 与 `index: true` 的 dense_vector；9.x 与内置客户端同主版本；7.17 及更低 dense_vector 不支持 index:true、维度上限 1024；IK 是插件需单独安装，缺失时索引照建、灌库照成功，只有中文检索质量下降且不报错。
- ES 弹窗底部 hint：「「测试连接」额外报版本、兼容性判读与 IK 分词器状态。」
- 向量弹窗预设 hint：同上预设 hint；底部 hint：「「测试连接」额外报版本、距离度量与已有集合数。」
- Qdrant 兼容折叠说明：「地址和度量改了会怎样？」—— 地址写完整 URL（各家形态差异大不拆两段）；度量与集合前缀不能热替换，改了等于换一套集合需重建重灌。

## 账号（account.html）

- 页头：「服务端只有一个账号：它回答"谁能进这个管控台 / 谁能调这个服务端"。这里只做改密码与查看信息。」
- 账号信息卡注：「密码以 BCrypt 单向哈希存储，不存明文，无法手工改文件，只能走本页的修改密码入口。本产品不提供密码找回，忘记请联系部署方。」
- 新密码 help 原文：「不超过 72 字节（UTF-8 下中文约 24 个字符）。BCrypt 的硬上限，超出会被拒。」（现仅留「不超过 72 字节」）
- 改密码弹窗折叠说明：「为什么改完会被踢下线？」—— 凭证是签名式（HMAC），签名密钥由【主密钥 + 密码哈希】派生，改密码后全部旧凭证签名立刻失效，本次登录也会被踢掉，保存后请重新登录。

## 知识库（knowledge.html）

- 页头：「文档由部署方自行上传维护；平台不内置任何知识内容。」
- 上传文档注：「同步导入：切片 + 向量化完成后才返回，大文件耗时较久。同名文档不区分大小写，默认拒绝；勾选「覆盖更新」则先删旧再写入。」
- 「归属域的作用」折叠说明：一个域对应一个独立索引，文档只有该域及其后代域能检索到；选根域 default = 全域可见；检索工具仍由部署方声明到哪些域，两层叠加。
- 索引重建注：「更换向量模型、或需要清空知识库时，手动触发索引重建（诊断 → 删旧 → 建 IK mapping → 校验）。重建会清空索引，已有文档需重新上传。」（警示改入重建确认弹窗）
- 重灌到新后端注：「把当前全部知识库内容（从 ChunkArchive 原文）重灌到指定目标后端。目标可以是当前向量后端（等价换向量模型保留原文重建），也可以是另一个已注册、具备向量存储能力的后端（换后端 = 一次重灌，不是数据迁移）。维度由当前向量模型决定，不可手动指定。」
- 文档清单注：「删除会释放该文件名，删除后同名文档可以再次上传。」（删除确认弹窗已有同义提示）
